## 本次更新

- **配额展示合并与视图统一**：移除账号管理顶部繁琐且割裂的“5H / 周配额”二选一切换按钮。账号卡片与表格视图合并展示双周期配额，默认直接对齐呈现 **Gemini 5H**（5小时滑动速率限额）与 **Gemini 7D**（7天周总配额），无需用户在两个视角间来回切换。
- **修复满额假象误导**：当配额处于 100% 满额就绪状态时，状态显示为绿色的“就绪 (Ready)”，鼠标悬停可查看底层重置基准；仅当额度被消耗（< 100%）时才显示黄色警告时钟与重置倒计时，彻底消除“明明 100% 满血却显示倒计时导致以为被冷冻”的困惑。
- **动态池拓展与表头规范**：表格列头对齐为“配额 (5H / 7D)”，排序支持优先综合 5H 与 7D 中更早的重置时间戳升降序排列。若用户在设置中自定义勾选了监控 Claude 等其他模型，系统会自动并列展示对应的 Claude 5H/7D；未勾选时默认纯净展示 Gemini。
- **移除首页综合额度卡片**：从仪表盘中彻底移除了冗余且计算维度模糊的“综合额度”卡片，优化网格布局为 9 项常用卡片。

## Changes

- **Merge 5H and Weekly Quota Views**: Remove the split "5H / Weekly" view-toggle buttons from the account management toolbar. Account cards and table rows now merge both time windows, defaulting to a clean, balanced display of **Gemini 5H** (5-hour sliding rate limit) and **Gemini 7D** (7-day total quota) without needing to flip perspectives.
- **Ready Indicator for Full Quota**: When quota is at 100%, the item displays a green "Ready" state (with the reset timestamp preserved in hover tooltips); countdown clocks and warning tones appear only when quota has been consumed (< 100%), resolving the confusion where fully available accounts appeared to be frozen.
- **Dynamic Pool Expansion & Header Alignment**: The table column header is updated to "Quota (5H / 7D)", and reset-time sorting uses the earliest available window timestamp. If the user pins Claude or other models in settings, the corresponding Claude 5H/7D rows expand automatically; otherwise, Gemini 5H/7D is displayed cleanly by default.
- **Remove Dashboard Aggregate Quota**: Remove the redundant and ambiguous "Aggregate Quota" card from the main dashboard overview, refining the dashboard grid to 9 focused metrics.

## Verification and limits

The quota view merging and 100% readiness indicator were verified with synthetic and real account snapshots on Windows. Automated unit tests in `scripts/test-menubar-logic.mjs` verify symmetric pool extraction across 5h and weekly windows, single-series filtering, and non-Gemini expansion when pinned. Dashboard overview tests in `scripts/test-dashboard-overview.mjs` verify 9-card catalog consistency and data anonymization.

Automated verification passed locally and in CI (36 menubar tests and 11 overview tests passed). Windows desktop binary builds cleanly through GitHub Actions.
